## 2. Embeddings

`codes/results/embeddings/<encoder>/{train,val,test}_embeddings.npy` (+ `_metadata.csv` with `idx, dataset_id, label_id, split, embedding_model`).
`float32`, mean pooling over `last_hidden_state` with the attention mask, `max_length=128`, `batch_size=16`, generated by cell 8 of `codes/01-ml-approach.ipynb` on GPU.

| Encoder alias | HF model | dim |
|---|---|---|
| `bertimbau_base` | `neuralmind/bert-base-portuguese-cased` | 768 |
| `bertimbau_large` | `neuralmind/bert-large-portuguese-cased` | 1024 |
| `albertina_ptbr_100m` | `PORTULAN/albertina-100m-portuguese-ptbr-encoder` | 768 |
| `albertina_ptbr_900m` | `PORTULAN/albertina-900m-portuguese-ptbr-encoder` | 1536 |

The `train_embeddings.npy` files (90-180 MB each) are Git LFS objects and were **not present locally** at the start (pointer files only). They were fetched with `git lfs pull --include=...`; after that every matrix has the expected shape and no non-finite values (`results/sanity/integrity_shapes.csv`). Instance order is identical across the four encoders for each split.

## 3. Splits

70/15/15, `train_test_split` stratified by `dataset_id__label_id`, `random_state=42`, two-stage (test first, then val with relative size 0.15/0.85). Implemented in `make_splits` of notebook 01.

## 4. Classifiers, grid search, selected hyper-parameters

Cell 9 of `codes/01-ml-approach.ipynb`:

* `GridSearchCV(scoring="f1_macro", cv=StratifiedKFold(3, shuffle=True, random_state=42))` fitted on **train only**.
* Pipelines with `StandardScaler` for `logreg, linearsvc, svc_rbf, gaussian_nb, knn`; none for `random_forest, gradient_boosting, decision_tree`.
* Validation metrics from the grid-search best estimator (trained on train); the **final model is refit on train+val** with the best parameters and evaluated on test.
* Selected hyper-parameters are stored as the `best_params` string column of `codes/results/classical_models/classical_models_results.csv` (32 rows, one per encoder x classifier). The extension parses them with `ast.literal_eval` (`extension/common.py::load_best_params`; copy in `results/sanity/selected_hyperparameters.csv`).

Grid (from the notebook): logreg C in {0.01,0.1,1,10} x solver {liblinear,lbfgs}; linearsvc C in {0.01,0.1,1,10}; svc_rbf C in {1,10}, gamma scale; RF n_estimators {200,500} x max_depth {None,20}; GB n_estimators {100,200}, lr 0.1, depth 3; GaussianNB var_smoothing {1e-9,1e-8}; kNN k in {3,5,7,11} x weights {uniform,distance}; DT max_depth {None,10,20,30} x min_samples_split {2,5,10} x criterion {gini,entropy}.

## Note on `codes/results/analysis_outputs_models` (added 2026-10-30)

Per-sample outputs of `codes/model_results_stat_analysis.py` for the 32 classical pipelines and 10 zero-shot LLMs
(`test/` and `val/`): metrics with bootstrap CIs, pairwise McNemar and Pearson tests, agreement distributions. The class
names of the classical rows follow the opposite convention to `codes/results/splits` (0 -> REAL there, 0 -> FAKE in the
splits); symmetric metrics are unaffected, per-class ones are swapped (see `extension/DECISIONS.md` D-26). The zero-shot
runs cover 5 765 of the 6 281 test items (no COVID19BR). `extension/make_baseline_figures.py` reads these files and
redraws the published analysis in English (`extension/FIGURES.md`).
